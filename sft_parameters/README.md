# SFT Parameters

LlamaFactory YAML configurations recording the settings used in the SFT and LoRA experiments.

## Contents

- Top-level YAML files: configurations for individual training and defense runs.
- `generated/`: learning-rate and LoRA-rank sweep configurations.

Filenames use `lr` for learning rate, `lora` for rank, `tall` for all target modules, `ecc` for the ECC variant, and `defense` for defense fine-tuning.
